# Northport Soccer Team

Single-page website: a series of photos, each with its own heading and text. Everything lives in `index.html` (no build step).

- **Preview:** open `index.html` in a browser.
- **Photos:** go in `images/`. Each `<section class="story">` in `index.html` is one photo and its text.
- **Team colors:** edit `--primary` / `--accent` at the top of the `<style>` block.
